The Xray node installer now asks before it installs: the panel address and
API key, then it lists all servers of the panel, marks the ones that point at
the server it runs on, and asks which of them this server runs (certificate
files and e-mail too). This release adds the list it reads from the panel.
On a node: bash <(curl -fsSL https://raw.githubusercontent.com/m0000hamad/xmplus-digitsell-patch/main/node/xray/install.sh)
