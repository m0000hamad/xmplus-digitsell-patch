Approval can now happen entirely inside Telegram. Settings -> Card to card takes an optional dedicated bot token (a second bot, separate from the panel's). On save the panel registers that bot's webhook (xmplus-patch.php?do=c2c.tgwebhook, with a secret header Telegram sends back) and the admin message carries callback buttons instead of URL links: tapping approve or reject decides on the spot, shows a toast, and removes the buttons from the message, with no page opening. Callback payloads are short (request id + an HMAC signed with the stored secret) and only chats in the admin chat list may decide. The webhook also answers /start so the admin knows the bot is ready. Without a dedicated token the old one-tap URL buttons remain, so nothing breaks. Customer messages still come from the panel's own bot.
