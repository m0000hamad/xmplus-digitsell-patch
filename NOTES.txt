Gift card redeem, redesigned - and a Telegram message when it lands.

The redeem dialog on the dashboard (view/user/dashboard/order.tpl, #redeem_modal)
is a warm gift card: gradient header with the gift badge, the code field drawn
as a ticket with a paste button, errors under the field with a shake, and a
success view with the result, the new wallet balance and "another card". The
request is still the panel's own POST /portal/redeem; Redeem() in
dashboard.tpl now shows the outcome inside the dialog instead of a layer popup.
Night theme follows html[data-hs-theme="dark"].

New GiftCardNotifyJob (bin/giftcards.php, every minute from TaskCommand) reads
giftcard_logs and sends the customer, through the panel bot, the amount added
and the wallet balance, and tells the admin chat who used which card. The
redeem endpoint is encoded, so the job works from the log. The first run marks
every existing redemption as already reported (giftcard_notify_last_id); set
giftcard_notify to 0 to switch it off.
