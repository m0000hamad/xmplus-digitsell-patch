OpenVPN over UDP and TCP, separately or together. The OpenVPN server now runs
a UDP and a TCP instance side by side (run the install command again once;
--proto both is the default), and each server in Settings -> OpenVPN servers
has a protocol choice (automatic / both / UDP only / TCP only) with separate
UDP and TCP ports. With both, customers get one file that tries UDP first and
TCP where UDP is blocked, plus a UDP-only and a TCP-only file.
