OpenVPN can now sit next to the other apps on the dashboard: add an app whose
name contains OpenVPN (e.g. "OpenVPN Connect") for each platform in the
panel's client apps list, where its download link, icon and guide are edited
like any other app. Its step shows the server files and the OpenVPN username
and password instead of the subscription link, and the separate OpenVPN card
is then hidden. The server file now tells OpenVPN Connect that no client
certificate is needed, so it stops asking for one; download the file again.
