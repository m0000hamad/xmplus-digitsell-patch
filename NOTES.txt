Theme switch on the sign-in page.

A three-way switch in the header - night, day, automatic (follows the
device) - picks the look of view/auth/login.tpl. Night is the default until
someone chooses. The choice is stored in the same localStorage key the panel
uses (hs_theme: dark / default / auto), so it carries into the dashboard
after signing in, and a choice already made inside the panel shows here too.
The theme is resolved before the first paint, so the page never flashes the
wrong colours; in automatic mode it follows the device changing live.
