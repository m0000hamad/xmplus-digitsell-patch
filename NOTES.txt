Xray nodes on the xhttp transport no longer take the panel down: the panel's
own link builders (app/Http/Schema) crashed on them, so the subscription link
and the user's Servers page answered "Internal Server Error" for every account
that could see such a node. The patch now fixes those files by itself when it is
installed, and checks them every hour, because a panel update puts the
originals back. Nothing to run by hand any more.
