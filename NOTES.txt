Two additions. Settings -> Card to card has a reset button that deletes every card-to-card request and confirmation (cards, settings and the orders themselves stay; the confirm dialog says so) - use it to clear the test data so the caps start at zero. And a test account: put a user id in "Test account user id" (the id shown next to the user in the Telegram message, usually 1). Requests from that account are applied normally but never count towards a card's cap, never appear in the admin history (they still show while pending, with a "تست" badge so the flow can be tried), and never produce a customer notice (no banner, no Telegram/e-mail). The Telegram admin message carries a "🧪 تست" line for them. 0 turns the test account off.
